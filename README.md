# Запись на приём к психологам — МГТУ

Сайт записи студентов/ППС/сотрудников на приём к психологам через
образовательный портал вуза. Чистый PHP (без фреймворка) + MySQL.

## Функции — что уже сделано

**Публично (без входа):**
- Список психологов, карточка с направлениями
- Выбор свободной даты/времени и запись на приём (форма ФИО/группа/телефон/комментарий)
- `/announcements` — групповые мероприятия и памятки (правила посещения/отмены, экстренная помощь)
- `/contacts` — раздел "Ссылки" (телефон экстренной помощи, ЦСИ «Пирамиды», ВК кафедры)

**Кабинет студента (`/cabinet`):**
- Список своих записей (прошлые и будущие)
- Запись на приём прямо из кабинета (без повторного ввода ФИО/телефона)
- Отмена записи — не позднее чем за 24 часа до приёма

**Кабинет психолога (`/dashboard`):**
- Список своих активных записей с контактами клиента
- `/dashboard/schedule` — управление расписанием: добавление/блокировка слотов,
  выбор формата (индивидуальный/групповой/семейный)
- Автоподсчёт недельной нагрузки, лимит 9ч/неделю — при превышении нужно
  явно отметить «экстренный случай», иначе слот не добавится
- `/dashboard/clients` — список всех клиентов, когда-либо обращавшихся
- `/dashboard/clients/show?id=` — история посещений конкретного клиента
- Заметки к записи — видны только психологам, клиент их не видит
- `/dashboard/announcements` — публикация мероприятий и памяток

**Админка (`/admin`):**
- Список психологов, создание нового психолога (учётка + профиль)
- `/admin/contacts` — управление разделом "Ссылки"

**Авторизация:** локальный логин/пароль для всех трёх ролей (студент,
психолог, админ), пока не подключён SSO портала вуза. Один `/login` на
все роли, после входа редиректит в нужный кабинет.

## Как запустить локально

Нужен PHP 8.0–8.3 и MySQL. Composer не используется — автозагрузка
классов своя, в `public/index.php` (12 строк, `spl_autoload_register`).

1. **PHP и MySQL**, если ещё не стоят:
   - Windows — [XAMPP](https://www.apachefriends.org/)
   - macOS — `brew install php@8.3 mysql`, `brew services start mysql`
   - Linux — `sudo apt install php php-mysql mysql-server`

2. **База данных** — обязательно с `--default-character-set=utf8mb4`,
   иначе русские буквы побьются при импорте:
   ```bash
   mysql -u root --default-character-set=utf8mb4 < database/schema.sql
   mysql -u root --default-character-set=utf8mb4 psycho_booking < database/seed.sql
   ```
   Если база уже существовала раньше и схема изменилась — пересоздайте:
   ```bash
   mysql -u root -e "DROP DATABASE psycho_booking;"
   ```
   и повторите импорт.

3. **Конфиг** — скопируйте пример и при необходимости поправьте:
   ```bash
   cp config/config.example.php config/config.php
   ```
   Дефолты (`root` / пустой пароль / `127.0.0.1:3306`) подходят для
   большинства локальных установок без правок.

4. **Запуск**:
   ```bash
   php -S localhost:8000 -t public
   ```
   Открыть http://localhost:8000. В PhpStorm то же самое — через
   `Run → Edit Configurations → PHP Built-in Web Server`, Document root: `public`.

## Основные нюансы

- **Кодировка при импорте БД** — всегда указывайте
  `--default-character-set=utf8mb4` в командах `mysql`, иначе кириллица
  в `schema.sql`/`seed.sql` испортится.
- **`config/config.php` коммитится в репозиторий** — решили не заводить
  `.gitignore` для него, репозиторий приватный (3 разработчика), проект
  временный (после сдачи заказчику будет удалён с GitHub). Если туда
  впишете боевые пароли — учтите, что они окажутся в истории git.
- **Заметки психолога** (`appointment_notes`) нигде не отдаются клиенту —
  ни в одном запросе `ClientController` эта таблица не участвует.
  Проверяйте это правило при добавлении новых страниц для студента.
- **Недельный лимit 9ч** считается по `YEARWEEK(slot_date, 3)` (ISO-неделя,
  Пн–Вс) суммой `free`+`booked` слотов психолога. `blocked` слоты в сумму
  не входят. Хранится на психологе индивидуально
  (`psychologist_profiles.max_hours_per_week`, по умолчанию 9).
- **Авторизация спроектирована под будущий SSO**: `src/Core/Auth.php` —
  сессии (не трогать), `src/Core/Auth/AuthProviderInterface.php` —
  контракт, `src/Core/Auth/LocalAuthProvider.php` — сегодняшняя проверка
  логин/пароль. Когда будет готов SSO вуза — добавить
  `SsoAuthProvider implements AuthProviderInterface` и поменять одну
  строку в `AuthController::login()`. Кабинеты и проверки ролей трогать
  не придётся.
- **Docker** — когда Максим пришлёт конфигурацию, меняется только
  `config/config.php` (хост БД), остальной код без изменений.

## Структура проекта

```
public/index.php          — точка входа, маршруты, автозагрузчик
src/Core/                 — роутер, БД, авторизация (Auth, AuthProvider)
src/Controllers/          — по контроллеру на раздел (Home, Booking,
                             Client, Psychologist, Admin, Announcement, Contact)
templates/                — php-шаблоны без движка (partials/, dashboard/, admin/)
database/schema.sql       — структура БД
database/seed.sql         — тестовые данные (5 аккаунтов, слоты, контакты)
config/config.example.php — шаблон конфига БД
```

## Маршруты (справочно)

| Маршрут | Доступ | Что делает |
|---|---|---|
| `GET /` | публично | Список психологов |
| `GET /psychologist?id=` | публично | Карточка психолога, выбор даты/времени |
| `GET,POST /book` | публично / студент | Форма и создание записи |
| `GET,POST /login`, `GET /logout` | публично | Вход/выход для всех ролей |
| `GET /cabinet`, `POST /cabinet/cancel` | студент | Кабинет, отмена записи |
| `GET /dashboard`, `/dashboard/schedule` | психолог | Записи, расписание |
| `POST /dashboard/schedule`, `/dashboard/schedule/block` | психолог | Добавить/заблокировать слот |
| `GET /dashboard/clients`, `/dashboard/clients/show` | психолог | Клиенты и история |
| `POST /dashboard/notes` | психолог | Заметка к записи |
| `GET,POST /dashboard/announcements(/delete)` | психолог, админ | Мероприятия/памятки |
| `GET /admin`, `/admin/psychologists/new`, `POST /admin/psychologists` | админ | Психологи |
| `GET,POST /admin/contacts(/delete)` | админ | Ссылки/контакты |
| `GET /announcements`, `/contacts` | публично | Публичные версии тех же разделов |
